# คำศัพท์สอบ 2–3 พฤศจิกายน 2569

เล่นที่ https://ditthakornm-star.github.io/eng-word-game/week-nov-2/

ชีทต้นฉบับ 15 รายการ ขยายรูปกริยา be, is, am, are, was, were, been, have, had, do, did, done รวมกับคำศัพท์อื่นเป็น 24 คำให้ฝึกสะกด คำว่า had ฝึกครั้งเดียวเพราะช่อง 2 และช่อง 3 สะกดเหมือนกัน

- `index.html` ระบบ V1 ดูคำก่อนสะกด คำใบ้ 2 ครั้ง โหมดยากไม่มีคำใบ้ ข้ามไปท้ายคิว เลือกคำแปลและฟังประโยค
- `vocabulary.js` คำศัพท์ ความหมาย ก้อนตัวสะกด และตัวอย่างประโยค การแบ่งก้อนบางคำเป็นตัวช่วยสะกด ไม่ใช่สัทอักษร ให้ฟังเสียงคำเต็มประกอบ
- `celebration.js` ฉากจรวด Three.js และดาว ตอบผ่านคำแล้วฉลอง มีปุ่มภาพนิ่งและเคารพการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์
- `vendor/three.module.js` Three.js 0.170.0 เก็บในเว็บ ใช้การอนุญาต MIT ตามหัวไฟล์
- `audio/ui` เสียงตอบถูก ผิด คำใบ้ แอบดู เลือกคำแปล และเสียงจบ ใช้ชุดเสียงจริงเดิม คำอังกฤษอ่านด้วยระบบ en-US
- `assets/source-nov-2.jpg` และ `assets/source-nov-3.jpg` ภาพคำศัพท์ต้นฉบับ

ฉากสามมิติมีตัวสำรองเมื่อ WebGL ใช้ไม่ได้ เกมยังเล่นต่อได้ ปุ่มปิดเสียงหยุดเสียงอ่านและไฟล์เสียงที่กำลังเล่น

ตรวจด้วย Playwright: เล่นครบ 24/24, คำที่ข้ามวนกลับ, คำใบ้, โหมดยาก, ปุ่มเสียงและภาพนิ่ง, หน้าจอ 390×844 และ 768×1024 พร้อมภาพและการตรวจพิกเซล WebGL
